# dutch-unemployment-amsterdam-surrounding-analysis
SQL and Power BI analysis of unemployment trends in Amsterdam and surrounding areas

This project analyzes unemployment trends in Amsterdam and surrounding areas using MySQL and Power BI.

## 🎯 Objectives

- Analyze unemployment trends over time
- Compare municipalities and regions
- Build interactive dashboards
- Extract insights using SQL queries

## 🛠️ Technologies

- MySQL  
- Power BI
- Data Cleaning
- Data Visualization

- ## 📈 Dashboard Features

The dashboard includes interactive visualizations such as:

- Unemployment by municipality
- Unemployement trends over time
- Municpality comparisons
- Comparison with country unemployment
- Interactive slicers and filters

---

## 📊 Key Insights

- Lelystad and Amsterdam has one of the highest unemployement rate.
- Regio-Haarlemmermeer and IJmondt have lowest unemployement rate.
- unemployment trend is stable  
- Interactive filtering makes it easy to compare municipalities by year.
