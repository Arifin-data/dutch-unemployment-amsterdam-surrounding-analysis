# dutch-unemployment-amsterdam-surrounding-analysis
SQL and Power BI analysis of unemployment trends in Amsterdam and surrounding areas

This project analyzes unemployment trends in Amsterdam and surrounding areas using MySQL and Power BI.

## 🎯 Objectives

- Analyze unemployment trends over time
- Compare municipalities and regions
- Build interactive dashboards
- Extract insights using SQL queries

## 🛠️ Technologies

- MySQL  
- Power BI
- Data Cleaning
- Data Visualization

## 📁 Repository Structure

- SQL scripts
- PowerBI report
